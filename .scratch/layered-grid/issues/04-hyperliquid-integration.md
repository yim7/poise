# 04：Hyperliquid 接入与启动文件

**要构建什么：** 用真实 Hyperliquid 运行任务 02 的最小网格：读取启动文件和私钥并校验，从旧代码复制并裁剪 Hyperliquid 适配，补齐任务 01 确认的接口，最后在测试网跑通。

**启动文件格式（已确定）：** 实例目录下的 `poise.toml`，由用户自己填写，权限必须是 600：

```toml
network = "testnet"                # testnet 或 mainnet
account_address = ""               # Hyperliquid 主账户地址
api_wallet_private_key = ""        # 授权给 Poise 的 API 钱包私钥，0x 加 64 个十六进制字符
data_dir = "data"                  # 数据库目录，相对本文件所在目录
listen = "127.0.0.1:8000"          # 网页控制台只监听本机
```

程序通过启动参数指定实例目录，只读取、不修改这个文件。

**测试网结果（2026-10-16）**：启动校验通过（Unified、推出的地址已授权且未过期）；远离市价挂单、查询、撤单通过；立即成交的小买单与只减仓平仓通过，仓位回到 0；2 格最小网格挂单与停止通过；强杀进程后重启无重复下单；带 `expiresAfter` 的下单被接受，过期动作被拒（`Action already expired`）。结束时无挂单、仓位为 0。

**实测结论**：`expiresAfter` 是动作送达期限，不是挂单寿命；签名需在 vault 标记后追加 `0x00` 与 8 字节大端毫秒时间戳（与官方 Python SDK 一致）。价格规则为最多 5 位有效数字、按价格分档。

**评审**：codex 评审后修复了多进程重复下单（加实例锁）、撤单类终态未识别导致永久卡住、`probe` 绕过持久化；启动文件权限按用户决定允许 400。
